# maximus-agent-access-review (incubator)

A repeatable review of what AI agents, coding tools, and MCP servers can reach: inventory with owners, capability and toxic-combination flags, risk ranking, right-sizing, tested revocation, traceability, and a recovery copy outside agent reach.

**Triggers:** "agent access review", "agent permissions audit", "least privilege agents", "revoke agent access", "shadow AI tools".

**Files:** `SKILL.md` (workflow), `HOWTO.md` (5 recipes), `references/agent-access-2026-10.md` (survey figures with sources), `examples/agent_inventory.csv` (sample inventory), `examples/score_inventory.py` (runnable scorer, tested on the sample).

**Siblings:** maximus-ai-safety-governance, maximus-agent-design, maximus-devops-ship, maximus-debug-incident, maximus-mcp-stateless-migration.

Drafted by the skill scout on 2026-10-07. Unreviewed until promoted. The scoring weights are a starting heuristic, not a standard.
