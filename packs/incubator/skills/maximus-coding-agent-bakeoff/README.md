# maximus-coding-agent-bakeoff (incubator)

Choose a coding agent (model plus harness) with a bake-off on tasks mined from your own merged PRs: repeated attempts, pass rates with intervals, cost per pass including failed runs, reward-hack audits, and anchor checks that show the benchmark measures skill.

**Triggers:** "which coding agent should we use", "compare Claude Code and Codex", "harness comparison", "coding agent benchmark on our repo", "cost per solved task".

**Files:** `SKILL.md` (workflow), `HOWTO.md` (5 recipes), `references/coding-agent-bakeoff-2026-11.md` (benchmark figures, method sources), `examples/bakeoff_report.py` (runnable scorer with anchor checks, tested on synthetic results).

**Siblings:** maximus-llm-model-selection, maximus-eval-and-test, maximus-k3-model-selection, maximus-parallel-agent-worktrees.
