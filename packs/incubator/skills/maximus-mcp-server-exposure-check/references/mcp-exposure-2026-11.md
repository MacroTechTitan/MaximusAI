# MCP server exposure — facts and sources (pulled 2026-11-25)

| Fact | Source |
|---|---|
| Spellwarden census of the official MCP Registry, 10 Nov 2026: 59,944 active entries; 30,402 hosts probed once each without credentials; 16,470 of 26,548 MCP hosts (62%) listed tools without sign-in; 9,691 open lists included at least one tool not declaring itself read-only; no tool was called; listing does not prove a tool is callable without sign-in; annotations are server claims | https://spellwarden.ai/research/mcp-server-security-2026-11 |
| Same report: the registry is in preview, holds metadata only, and does not verify that a remote URL belongs to its publisher; recommends requiring sign-in for anything not public by design, publishing protected-resource metadata, honest `readOnlyHint`/`destructiveHint`, descriptions limited to what the tool does, and container images pinned by digest (17 of 1,729 were) | same |
| mcpprobe passive survey, snapshot 31 Oct 2026: 55.7% of assessable remote servers (11,682 of 20,981) answered without login; 15.1% of servers requiring login (1,395 of 9,255) published no usable RFC 9728 metadata; 19.6% of open servers had complete, consistent tool annotations; 102 open servers offered command execution or file access with no login; 18.1% of open servers combined tools that read private data, take untrusted input, and send data out (risk indicator, not a demonstrated attack) | https://mcpprobe.tech/research/state-of-mcp-security |
| NX Dev Solutions roundup (10 Nov 2026): about 30 NVD records matching "MCP" from 1-10 Nov 2026; bug classes include shared transport leaks, token audience not checked (TypeScript SDK accepted tokens minted for another service), headers leaked on cross-origin redirect, OAuth resource confusion, path traversal, SSRF via IPv4-mapped IPv6, tools skipping app authorization, unauthenticated listeners with shell execution | https://nxdevsolutions.com/blog/mcp-server-cve-november-2026 |
| Fixed versions per the same page: `@modelcontextprotocol/sdk` 1.32.0, `@modelcontextprotocol/server` 2.3.0, `@modelcontextprotocol/client` 2.3.0, `@modelcontextprotocol/express` 2.0.2; the audience check and input bound need configuration; shared server or transport fails with `ALREADY_CONNECTED` on 2.3.0 | same |
| Scout run 2026-11-25: `examples/mcp_exposure_check.py` against `examples/mock_server.py` returned exit 1 with four findings (open list, missing annotations, model-directed text, read-plus-send) in `open` mode, exit 0 in `auth` mode with metadata found, exit 0 in `clean --public-ok`, exit 2 on a closed port | local run |
