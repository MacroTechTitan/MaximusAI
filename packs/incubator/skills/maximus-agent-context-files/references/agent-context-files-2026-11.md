# Agent context files — facts and sources (pulled 2026-11-04)

| Fact | Source |
|---|---|
| Study (arXiv 2611.04367, Nov 3, 2026): one policy (add `# @tracked` below every added or modified Python def) inserted in four styles (Prescriptive, Explanatory, Conditional, Prohibitive) as the last line of the context files of 86 CTXbench tasks from 10 repositories; four harness-model combinations, three repetitions; a session counted as compliant only if every target function had the marker | https://arxiv.org/html/2611.04367v1 |
| Compliance, Prescriptive / Explanatory / Conditional / Prohibitive: Claude Code + claude-opus-5 78.0 / 77.2 / 64.2 / 70.7%; Claude Code + claude-sonnet-5 71.6 / 49.4 / 35.6 / 17.3%; qwen-code + gpt-oss-120b 6.7 / 20.4 / 0.8 / 0.4%; qwen-code + Qwen3-Coder-Next 1.3 / 0.8 / 0.4 / 0.0% | same |
| Style significantly affected compliance in 3 of 4 combinations; in all three, Prescriptive and Explanatory beat Conditional | same |
| Claude Code docs: CLAUDE.md, prompts, and skills are non-deterministic (the model decides); hooks, deny rules, and managed settings are deterministic (the harness applies them every time). "If something has to happen every time, make it a hook, a deny rule, or a managed setting." `prompt` and `agent` hooks ask another model and are not deterministic; use `command` or `http` hooks, with `onFailure: "block"` to also stop on hook crash or timeout. Deny rules hold in every permission mode | https://code.claude.com/docs/en/best-practices |
| Claude Code docs: target under 200 lines per CLAUDE.md; files over 4 MiB are skipped at launch; `@path` imports do not reduce context use; discovered files are concatenated, not overridden; contradictory instructions may lead Claude to follow either one; `.claude/rules/` files with `paths` frontmatter load only when matching files are touched | https://code.claude.com/docs/en/claude-md |
| Claude Code hooks: PreToolUse receives `tool_name` and `tool_input`; exit code 2 blocks the call and sends stderr to Claude; JSON `permissionDecision: "deny"` also blocks; decision precedence deny > defer > ask > allow | https://code.claude.com/docs/en/hooks |
| Codex: concatenates AGENTS.md files from the project root down to the working directory (at most one file per directory, `AGENTS.override.md` first); `project_doc_max_bytes` defaults to 32 KiB, after which files stop being added | https://developers.openai.com/codex/guides/agents-md |
| Arcjet (Nov 2026): instruction files cannot enforce security rules because injected text, misapplication, context compaction, or file edits can defeat them; keep the rule in the file and enforce it with a hook policy; hooks only count if developers and agents cannot turn them off (managed settings) | https://arcjet.com/learn/agents-md-is-not-a-security-control |
| Audit-trail study (arXiv 2611.05094, Nov 4, 2026): in a spec-driven Claude Code workflow where almost all controls were instructions ("enforcement by persuasion"), the orchestrator's self-run block check flagged 11 of 247 checks and stopped the round in only 4 | https://arxiv.org/pdf/2611.05094 |
| Scout run 2026-11-04: `examples/rule_compliance.py` tested on synthetic session diffs (reported 1/2 and 2/3 compliance correctly, excluded non-triggering sessions); `examples/deny_env_read.py` exited 2 for `.env` and `.env.local` inputs and 0 for `src/env.py` | local run |
